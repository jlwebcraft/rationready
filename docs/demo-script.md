# RationReady — Demo Script (Under 3 Minutes)

> **Event:** Techfest 2026–27 Campus to Cloud Hackathon  
> **Status:** Draft / Outline for Phase 7

---

## Scene Timing (180 Seconds Total)

1. **0:00 - 0:25 (The Problem):** The daily challenge faced by ration cardholders traveling to Fair Price Shops without knowing crowd levels, ePOS status, or stock.
2. **0:25 - 0:50 (The Solution):** Introduction to RationReady ("Know before you go") and the 4 core visit questions.
3. **0:50 - 1:30 (Live Prototype Walkthrough):** Browsing shops in Demo Locality A, viewing current queue wait, ePOS status, and stock availability.
4. **1:30 - 2:00 (Citizen Report Submission):** Submitting a 15-minute queue update, immediate server-side aggregation, and confidence level transition.
5. **2:00 - 2:30 (AWS Serverless Architecture):** Highlighting AWS Lambda (Node.js 22), DynamoDB with TTL, Cognito, and API Gateway in `ap-south-1`.
6. **2:30 - 3:00 (Impact & Privacy Guardrails):** Impact hypothesis, strict privacy protections (no Aadhaar/ration card storage), and closing statement.
